# rowkit

The image builds `src/`, Team 67's pipeline (github.com/nimaibhat/databricks-chall,
commit e536e7b; published earlier as jason-scheffel/express-lane), used under the MIT
License that the event requires. Team 67's copyright notice is kept in `LICENSE`.
It needs AVX-512 (built for Cascade Lake).

`legacy/` holds our own pipeline (generic path tuned for the opaque-ID data format).
It is kept for reference and is not part of the image.
